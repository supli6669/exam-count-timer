# Workspace Rules: 20 Essential Modern Web Standards

1. **UI/UX Aesthetics (`web-performance-uiux`)**: Ultra-premium interfaces with dark mode tokens, glassmorphism, responsive micro-interactions, and visual depth.
2. **60fps Rendering (`web-performance-uiux`)**: Animate only GPU-composited CSS properties (`transform`, `opacity`). Avoid layout reflows (`width`, `height`, `top`, `left`).
3. **PWA & Offline First (`pwa-offline-storage`)**: Service worker caching strategies, IndexedDB & LocalStorage persistence, and Web Notifications.
4. **Web Audio API (`web-audio-soundboard`)**: Autoplay policy handling, procedural sound synthesis, and zero-latency soundboard triggers.
5. **Accessibility & Focus (`web-accessibility-keyboard-ux`)**: Keyboard navigation (`Tab`, `Enter`, `Space`, `Esc`), visible `:focus-visible`, and screen reader announcements (`aria-live`).
6. **State Architecture (`react-state-architecture`)**: Isolated leaf component state, Context API optimization, dynamic vs dispatch context splitting.
7. **Micro-Animations (`micro-animations-gestures`)**: Spring physics, snappy active feedback (`scale(0.96)`), pointer gesture hooks, and staggered card entrances.
8. **Fluid Layouts (`responsive-fluid-layouts`)**: `100dvh` mobile height, container queries (`@container`), CSS Grid auto-fit, and fluid `clamp()` typography.
9. **Theme Engine (`dark-light-theme-engine`)**: HSL/OKLCH color space systems, FOUC prevention, system theme sync, dynamic glow tokens.
10. **Form UX (`form-validation-ux`)**: Inline validation on blur, debounced typing checks, accessible error descriptions (`aria-describedby`), double-submit prevention.
11. **Canvas & Charts (`canvas-chart-visualization`)**: Retina DPR scaling, `requestAnimationFrame` render loops, offscreen canvas caching, 60fps particle effects.
12. **Web Security (`web-security-csp-xss`)**: XSS sanitization, safe URL protocols, secret protection, `rel="noopener noreferrer"` external links.
13. **Bundle Optimization (`bundle-optimization-tree-shaking`)**: React `lazy`/`Suspense` route dynamic imports, ESM named imports, bundle visualizer auditing.
14. **Network Resilience (`network-resilience-retry`)**: Exponential backoff retries, `AbortSignal.timeout`, optimistic UI updates, offline queue sync.
15. **Error Boundaries (`error-boundary-resilience`)**: Granular component error boundaries, self-healing reset fallbacks, crash logging.
16. **SEO & Metadata (`seo-meta-open-graph`)**: Dynamic document titles, OpenGraph social cards, SVG + PNG icons, canonical links.
17. **Internationalization (`i18n-localization`)**: Native `Intl` APIs, translation key fallbacks, pluralization rules, CSS logical properties for RTL.
18. **Custom Hooks (`custom-hooks-library`)**: Reusable hooks (`useDebounce`, `useLocalStorage`, `useEventListener`, `useIntersectionObserver`).
19. **Drag & Drop (`drag-and-drop-ux`)**: Touch & pointer drag gestures, visual drop zone cues, ghost drag images, keyboard reordering fallbacks.
20. **Core Web Vitals (`web-vitals-monitoring`)**: LCP, INP (<50ms), CLS tracking, `performance.mark` benchmarking, development render warnings.
