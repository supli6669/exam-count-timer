# Drag and Drop UX Guidelines

Use this skill when implementing card reordering, list sorting, item drag-and-drop interactions, or drop zones.

## Guidelines
1. **Pointer & Touch Support**: Support both desktop mouse dragging and touch screen drag gestures seamlessly.
2. **Visual Drop Cues**: Highlight target drop zones with a distinct dashed border and glowing background when items are dragged over them.
3. **Ghost Drag Image**: Custom style the drag preview ghost element for clear feedback.
4. **Keyboard Reordering**: Always provide keyboard alternatives (e.g. Move Up / Move Down buttons) for accessibility compliance.
