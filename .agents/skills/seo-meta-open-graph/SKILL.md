# SEO & Meta Open Graph Guidelines

Use this skill when setting up document head tags, dynamic page titles, social sharing previews, or structured metadata.

## Guidelines
1. **Dynamic Document Title**: Update `document.title` on view/route changes (e.g. `"(04:59) Exam Timer - Math Test"`).
2. **Open Graph Metadata**: Include `og:title`, `og:description`, `og:image`, and `og:url` tags in HTML head for rich link previews when shared on Messaging apps or Social Media.
3. **Favicon & PWA Icons**: Provide 192x192 and 512x512 PNG icons alongside SVG favicons for mobile homescreen shortcuts.
4. **Canonical URLs**: Define `<link rel="canonical">` to prevent duplicate content indexing issues.
